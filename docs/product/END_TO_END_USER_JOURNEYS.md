# End-to-end user journeys

## Hackathon first

Enter a brief, review the parsed working context, correct it, confirm it, generate a nine-strategy local slate, inspect a version, challenge it, choose a second version for comparison, combine if useful, then create, review and export a version-bound blueprint.

## Idea first

Enter an original idea. The original is stored separately and shown unchanged beside the editable working interpretation. Confirm, generate alternatives, branch or challenge a version, choose two explicit parents for combination, inspect lineage, then create a blueprint.

## Interrupted work

An unconfirmed review returns to review after refresh. A submitted job ID is retained locally; refresh resumes reads of that job instead of dispatching another. Selected version is remembered per private session. Expired guest access requires starting a new private session; it does not expose another owner's work.

## Evidence boundary

Research shows stored claim records and their verification status. No source connector runs in this sprint. Deterministic generation is labeled as such. The product does not assert that an unobserved comparable project proves originality.
