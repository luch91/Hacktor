# Information architecture

Home offers two entry paths, hackathon brief and original idea. Both enter a private review checkpoint before Studio. Studio keeps one selected immutable idea version and eight ordered stage views: Understand, Map, Diverge, Interrogate, Evolve, Research, Converge and Blueprint.

The center holds the current stage and idea slate. The inspector holds version detail, actions and explicit second-version selection. On narrow screens the stage list scrolls horizontally and the inspector follows the main task. Backend stage status remains the authority; opening a stage does not mark it complete.

Exploration uses strategy cards and lineage. Evidence uses claim status and source limitations. Decisions use pinning, rejection, explicit comparison and a blueprint bound to one version. No displayed score implies verified originality.
